Claude Console

把左边的 Claude Console 拖到右边的 Applications 文件夹

Drag Claude Console onto Applications to install it. If asked, choose Replace.

复制完后推出这个磁盘，再从「应用程序」打开 Claude Console

Then eject this disk and open Claude Console from Applications.

第一次打开 · First start

macOS 提示无法验证时，点「完成」关掉提示，不要点「移到废纸篓」

If macOS cannot verify the app, click Done. Do not move it to the Trash.

再到「系统设置 › 隐私与安全性」点「仍要打开」，并在新窗口里确认

Then click Open Anyway in System Settings › Privacy & Security, and confirm.
